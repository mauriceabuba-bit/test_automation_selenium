# Website Navigation Automation Test Plan

## 1. Objective
To verify that the portfolio website navigation links work correctly and that a nonexistent link cannot be found.

## 2. Test Environment
- Operating system: Windows 10
- Browser: Google Chrome
- Automation tool: Python with Selenium WebDriver
- Website: Local portfolio website (`index.html`)

## 3. Test Cases

| Test ID | Test Description | Expected Result |
|---|---|---|
| TC-01 | Click the Home link | URL ends with #home |
| TC-02 | Click the About link | URL ends with #about |
| TC-03 | Click the Skills link | URL ends with #skills |
| TC-04 | Click the Projects link | URL ends with #projects |
| TC-05 | Click the Contact link | URL ends with #contact |
| TC-06 | Search for a nonexistent navigation link | Selenium reports that the link cannot be found |

## 4. Execution and Logging
The test script runs each test independently and records the test ID, expected result, actual result, status, duration, and relevant error details. It records browser and operating system information and produces a timestamped log file for each run.

## 5. Pass/Fail Criteria
A test passes when the actual result matches the expected result. A test fails when the expected result is not achieved. The negative test passes when the nonexistent link is not found.
